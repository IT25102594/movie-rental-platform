🚀 Full CRUD Implementation

➕ CREATE - SubmitReviewServlet

Purpose: Submit new reviews to the system

File: SubmitReviewServlet.java

Process:

  1. Accepts form data (movieId, rating, reviewText)
  2. Generates unique review ID
  3. Creates appropriate Review object (Guest or Verified)
  4. Saves to data/review.txt
POST /SubmitReviewServlet
movieId=M001
rating=5
reviewText=Great movie!
📖 READ - ViewReviewsServlet

Purpose: Display all reviews in a formatted table

File: ViewReviewsServlet.java

Process:

  1. Reads all lines from data/review.txt
  2. Parses each line into Review objects
  3. Uses Polymorphism (Guest/Verified)
  4. Forwards to viewreviews.jsp
GET /ViewReviewsServlet

Returns: List<Review>
✏️ UPDATE - EditReviewServlet

Purpose: Edit existing reviews

File: EditReviewServlet.java

Process:

  1. GET: Loads review by ID into edit form
  2. POST: Updates rating and text in file
  3. Overwrites matching line in data/review.txt
  4. Redirects to ViewReviewsServlet
GET /EditReviewServlet?reviewId=RV001
POST updates rating & text
🗑️ DELETE - DeleteReviewServlet

Purpose: Remove reviews from the system

File: DeleteReviewServlet.java

Process:

  1. Accepts reviewId parameter
  2. Filters out matching line using Stream API
  3. Overwrites data/review.txt
  4. Redirects to ViewReviewsServlet
GET /DeleteReviewServlet?reviewId=RV001

Review is permanently removed

🏗️ System Architecture

Class Hierarchy (Inheritance & Polymorphism)
Review (Abstract Base Class) ├── GuestReview → getReviewType() returns "GUEST" └── VerifiedRenterReview → getReviewType() returns "VERIFIED"
MVC Pattern
  • Model: Review, GuestReview, VerifiedRenterReview classes
  • View: write.jsp, viewreviews.jsp, edit.jsp
  • Controller: SubmitReviewServlet, ViewReviewsServlet, EditReviewServlet, DeleteReviewServlet
  • Utility: FileHandler for file I/O operations

📁 Project File Structure

movie-rental-platform/ ├── src/main/java/com/movieplatform/ │ ├── MovieRentalApplication.java (Spring Boot entry point) │ ├── Review.java (Abstract base class) │ ├── GuestReview.java (Subclass) │ ├── VerifiedRenterReview.java (Subclass) │ ├── SubmitReviewServlet.java (CREATE) │ ├── ViewReviewsServlet.java (READ) │ ├── EditReviewServlet.java (UPDATE) │ ├── DeleteReviewServlet.java (DELETE) │ └── FileHandler.java (Utility for file operations) │ ├── src/main/webapp/views/review/ │ ├── write.jsp (Create form) │ ├── viewreviews.jsp (Read/display) │ └── edit.jsp (Update form) │ └── data/ └── review.txt (Data persistence file)
